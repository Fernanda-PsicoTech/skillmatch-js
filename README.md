SkillMatch JS
Objetivo
O SkillMatch JS é um simulador de compatibilidade entre candidatos e vagas Front-End Júnior.

O sistema compara as habilidades da candidata com os requisitos das vagas e apresenta:

Percentual de compatibilidade;
Classificação da compatibilidade;
Habilidades faltantes;
Vaga mais compatível;
Sugestão de estudos.
Como executar
Abrir o projeto no VS Code.
Abrir o terminal.
Executar o comando:
node skillmatch.js

Regra de cálculo da compatibilidade
A compatibilidade é calculada através da seguinte fórmula:

(Habilidades encontradas ÷ Total de requisitos da vaga) × 100

Critério de recomendação de estudo
As habilidades que a candidata ainda não possui são apresentadas como recomendação de estudo.
